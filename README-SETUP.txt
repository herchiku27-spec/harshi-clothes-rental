HARSHI CLOTHES RENTAL — STARTER WEBSITE
========================================

FILES
- index.html  : website content
- style.css   : design and responsive layout
- script.js   : menu, category filters and WhatsApp enquiry form

IMPORTANT BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Replace 947XXXXXXXX with your real WhatsApp number in international format.
   Sri Lanka example: 94771234567 (digits only; no + or spaces).
3. Open index.html and replace the sample wording with your real business details.
4. Replace the decorative sample costume cards with real photos and accurate rental details.
   The current cards are illustrations, not actual product photographs.
5. Do not publish made-up prices, availability, address or contact details.

HOW TO PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the harshi_clothes_rental folder.
3. Double-click index.html. It opens in your browser.
4. Edit the files with a free editor such as Visual Studio Code.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Create a free account at https://github.com/
2. Create a new repository. Name it: harshi-clothes-rental
3. Set it to Public and create the repository.
4. Choose Add file > Upload files.
5. Upload index.html, style.css and script.js (not just the ZIP).
6. Commit the files.
7. Open the repository Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a few minutes. GitHub will show your free website address:
    https://YOUR-USERNAME.github.io/harshi-clothes-rental/

HOW TO UPDATE
Edit the relevant file, upload the changed file to the same repository path,
and commit the change. GitHub Pages republishes it automatically.

FREE TOOLS
- Visual Studio Code: https://code.visualstudio.com/
- GitHub: https://github.com/
- GitHub Pages guide: https://docs.github.com/en/pages

NOTE
This is a front-end starter website. The enquiry form opens WhatsApp with a
pre-filled message; it does not store bookings in a database. Online payments,
admin login, stock tracking and automatic booking confirmations would need
additional services or a backend.
